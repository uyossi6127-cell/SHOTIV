# Shotiv

אפליקציה בעברית למטופלי תרופות הרזיה (מונג'רו, וויגובי): תזכורת לזריקה, מעקב משקל מול יעד ויומן תופעות לוואי.

פרויקט גמר בקורס ניהול מוצר. נבנה בשיטת Agile, בספרינטים של שבועיים.

## מה עובד עכשיו (ספרינט 1)

- **S9** · התקנה על הטלפון כ-Web App (PWA), עובד גם בלי אינטרנט
- **S1** · הרשמה ראשונית: תרופה, מינון, יום זריקה, משקל ויעד
- **S2** · מסך בית: ספירה לאחור לזריקה הבאה והתקדמות מול היעד

## איך מתקינים על הטלפון

- **אייפון (Safari):** כפתור השיתוף ← "הוסף למסך הבית"
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקן אפליקציה"

## פרטיות

כל הנתונים נשמרים על המכשיר בלבד. אין שרת ואין חשבון.

## אחריות

האפליקציה מתעדת בלבד ואינה ממליצה על מינון. את המינון קובע הרופא.
